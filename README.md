# AI 味：写作为什么"像 AI 写的"，以及怎么办

**AI flavor in writing: what makes text sound like AI, why it happens, and how to fix it.**

这个仓库深入研究写作中的"AI 味"：它由什么组成、从哪里来、能不能被认出来、怎么去掉，以及去掉它的边界在哪里。内容包括中英文研究综述（2021–2026，引用逐条打开原文核对）、一个中英文都能用的诊断工具，以及一次同题对照实验。

> 英文没有统一的术语。最接近"有 AI 味"的说法是 **"it sounds like AI"**；具体的露馅特征叫 **AI tells**；AI 爱用的词句叫 **AI-isms**；大量低质 AI 内容叫 **AI slop**。见[第一章](docs/01-overview.md)。

## 一页结论

**AI 味是什么**
- 它分好几层：用词（赋能、值得注意的是、delve、tapestry）、句式（"不是……而是……"、"It's not X, it's Y"）、节奏（句子长短太平均）、结构（首先 / 其次 / 总之、分点、加粗）、内容（结尾升华、缺少具体细节）、声音（中性、安全、面面俱到）。
- 职业作家把 AI 文字的问题归成 7 类：陈词滥调、不必要的解释、辞藻堆砌、句子结构差、缺少具体细节、用词别扭、时态不一致（Chakrabarty 等，CHI 2025）。

**它从哪里来**
- 主要来自**后训练**（指令微调、RLHF）。同一系列模型里，没有后训练的基础模型反而更接近人的用词和语法；GPT-4o 用现在分词从句的频率约为人的 5.3 倍，名词化约 2.1 倍（Reinhart 等，PNAS 2025）。
- 它正在扩散到人类语言里：2024 年 PubMed 摘要中至少 13.5% 经过 LLM 处理（Kobak 等，Science Advances 2025）；用 LLM 润色会让写作复杂度的差异缩小 21%–50%（Sourati 等，Nature Human Behaviour 2026）。

**能不能认出来**
- 普通人基本认不出；但经常用 AI 写作的人可以：5 位这样的读者投票判断，300 篇文章只错 1 篇（Russell 等，ACL 2025）。也有 2026 年的研究得出相反的结论，见[第二章](docs/02-literature-en.md)。
- 自动检测器靠不住：改写就能绕过，还会误判非母语作者。
- 读者一旦知道有 AI 参与，就会打折，原因是"不真实"（27,491 人，16 个实验，J Exp Psych: General 2026）。

**怎么去掉**（证据最强的三种，见[第四章](docs/04-solutions.md)）
1. **人先写，AI 只做修改**。人修改 AI 的初稿，结果仍然偏 AI 风格，而且自己察觉不到。
2. **按 7 类问题逐段修改**：作家修改 > 自动修改 > 原稿。
3. **用作者自己的作品微调**：效果最好，但有版权和冒充的风险。

还有两个反直觉的发现：用 DPO 训练模型避开"slop 短语"会让质量和多样性下降；现成的 LLM 给写作打分接近随机。

**我们自己的实验**（[第六章](docs/06-experiment.md)）：13 篇鲁迅、朱自清、徐志摩的散文，对比 3 个模型 × 2 种提示词写的 78 篇同题散文：
- 词表和形式信号**区分不了**人写和模型写的散文（AUC 0.46）。现代模型写散文时几乎不用套话。
- 唯一明显的词汇标记是 **"不是……而是……"**：模型 39 篇出现 14 次，人写 13 篇 0 次。
- 去 AI 味提示让 39 篇里 36 篇降分，但又长出一种新的 AI 味：**清单式细节**（"去年十一月的一个周六，下午三点多，合肥，银泰三楼"）。
- 散文里真正的 AI 味在更高的层次：**结尾升华成金句**、叙事中插入人生道理、蒙太奇式的结构。

**边界**（[第八章](docs/08-ethics.md)）：去 AI 味是为了写得更好，不是为了让人看不出用了 AI。在中国，《人工智能生成合成内容标识办法》自 2025-09-01 起施行，用户发布 AI 生成的内容**应当主动声明**，不得删除或隐匿标识。

## 诊断工具 `aiflavor`

只依赖 Python 3.9+ 标准库，中英文都能用。**它不是 AI 检测器**，分数只适合比较同一篇文字改稿前后的变化。它适合检查说明文、报告、公文、营销文；对散文和小说基本无效（见第六章）。

```bash
git clone https://github.com/tsaol/ai-wei && cd ai-wei
export PYTHONPATH=tools
python -m aiflavor examples/ai_sample_zh.txt examples/rewrite_zh.txt   # 对比两个版本
python -m aiflavor 文章.txt --html 报告.html                            # 高亮可疑的地方
```

```
== examples/ai_sample_zh.txt  [zh] 185 字符, 9 句
AI 味指数: 68.5 / 100
  套话和套路句式        ████████████████████ 1.00 × 35
  句长太均匀          ███████████████████· 0.95 × 20
  ...
  建议:
    * 删掉或换掉这些套话：「在……背景下/随着……」×1、「首先……其次」×1、「赋能」×1
    * 句子长短太平均（变异系数 0.27）。加几个很短的句子，或者把一个判断写长、写透
    * 太空泛：加一个具体的数字、名字、场景或别人说过的原话

对比: examples/ai_sample_zh.txt: 68.5 | examples/rewrite_zh.txt: 2.9
```

词表在 [`tools/aiflavor/lexicons/`](tools/aiflavor/lexicons/)，每一条都标了证据强度（研究 / 多来源经验 / 单一来源）。欢迎补充。
