# 第十一章 推荐阅读：全球写得好的技术写作者

> 2026-10-18 整理，所有链接当天打开验证过。"好在哪里"是维护者和 AI 助手的判断；"许可"是在首页上看到的声明，没看到的写"未声明"，表示默认保留所有权利。本仓库只收录有开放许可的全文，其他只放链接。

## 先读这三篇

- Paul Graham，[Write Simply](https://paulgraham.com/simply.html)：讲写作本身，很短。
- Julia Evans，[A debugging manifesto](https://jvns.ca/blog/2022/12/08/a-debugging-manifesto/)：讲解型的范本。
- Dan Luu，[I could do that in a weekend!](https://danluu.com/sounds-easy/)：观点型的范本。
