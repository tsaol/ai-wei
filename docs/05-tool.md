# 第五章 `aiflavor`：AI 味诊断工具

## 它是什么，不是什么

`aiflavor` 把一段文字里**可能让人觉得像 AI 写的地方**找出来，说明原因，并给出修改建议。

它**不是 AI 检测器**，也不应该被当成检测器使用：

- 第二章第六节的研究表明，自动检测器在文字被改写后很容易失效，还会把非母语作者的文章误判成 AI 写的。
- 人写的文字也会有套话、模板和空泛的段落；AI 写的文字经过修改，也可以一个信号都不触发。
- 所以分数只适合**比较同一位作者、同一篇文字的不同版本**，比如改稿前后，不能用来判断"这段是不是 AI 写的"，更不能用来处罚任何人。

## 安装和使用

只依赖 Python 3.9+ 标准库。

```bash
git clone https://github.com/tsaol/ai-wei && cd ai-wei
export PYTHONPATH=tools

python -m aiflavor 文章.txt                  # 终端输出
python -m aiflavor 文章.txt --json           # JSON
python -m aiflavor 文章.txt --html 报告.html  # 把命中的地方高亮
python -m aiflavor 初稿.txt 修改稿.txt         # 对比两个版本
cat 文章.txt | python -m aiflavor -          # 从标准输入读
```

在 Python 里调用：

```python
from aiflavor import analyze
r = analyze(text)            # 自动判断中文 / 英文
print(r.score, r.parts, r.advice)
for h in r.hits:
    print(h.text, h.label, h.note)
```

## 六个信号

| 信号 | 权重 | 怎么算 | 依据 |
|---|---|---|---|
| 套话和套路句式 | 35 | 词表命中数，按证据强度加权（研究 1.0 / 多来源经验 0.8 / 单一来源 0.4），换算成每千字（中文）或每千词（英文）的密度 | 第二章第二节、第三章的标记清单 |
| 句长太均匀 | 20 | 句子长度的变异系数（CV）。CV 越低，句子长短越平均 | 社科院文章（"长短过于均衡"）、Russell 等专家线索（"句长太均匀"） |
| 模板化结构 | 15 | 分点行、小标题行、加粗片段的比例，加上"首先……其次""总之"这类结构标记 | 实践清单、专家线索 |
| 破折号 / 冒号 / emoji | 10 | 每千字的密度 | 实践清单。注意：维基百科 2026 年已把"大量用破折号"列为"历史特征"，新模型用得少了 |
| 重复 | 10 | 句子之间共享的 n-gram（中文 6 字，英文 4 词），只抓重复的说法，不算反复出现的话题词 | slop 测量研究中的 repetition |
| 空泛 | 10 | 具体信息的密度：数字、引语、专有名词。越少越空泛 | 作家标注的"缺少具体细节"、slop 研究中的 density |

总分 = Σ 权重 × 信号强度（0–1），范围 0–100。

**为了避免短文本被放大**，密度按"最少 300 字 / 200 词"计算：一段 70 词的英文里有一个冒号，不会因此被判成"冒号过多"。

## 词表

`tools/aiflavor/lexicons/zh.json` 和 `en.json`，每一项：

```json
{"pattern": "正则表达式", "label": "名称", "type": "lexical|syntax|structure|rhetoric|content",
 "evidence": "research|multi|single", "note": "说明和来源"}
```

- `research`：有研究直接支持（比如 delve、具有重要意义）。
- `multi`：多个独立的实践来源都提到，但没有系统研究。
- `single`：只有单一来源，权重最低。

可以用 `--lexicon 我的词表.json` 加入自己的词表，比如某个行业、某家公司的套话。

## 权重是怎么定的，效果怎么样

权重是**经验设定**，不是从数据里训练出来的。第六章用 13 篇公有领域散文和 78 篇模型写的同题散文做了检验，结果很直接：

- **在文学性文字上，工具区分不了人写和模型写**（AUC 0.46，等于瞎猜）。现代模型写散文时几乎不用词表里的套话；1920 年代的白话散文反而有更多排比、破折号和重复。
- 六个信号里只有**句长均匀度**有区分度（AUC 0.82）。词汇标记里只有 **"不是……而是……"** 明显（模型 39 篇里出现 14 次，人写 13 篇里 0 次）。
- **分数很容易被提示词"教"下去**：加一段去 AI 味的要求，39 篇里有 36 篇降分，但读起来又出现了"清单式细节"这种新的 AI 味。

所以：

- **适合**：说明文、报告、公文、营销文、公众号文章这类实用文字。第三章的大部分标记来自这些文体，套话和模板在这里最常见。
- **不适合**：散文、小说、诗歌，以及任何需要判断"是不是 AI 写的"场合。
- 我们**没有**照着这次的实验数据调整权重，因为人写样本只有 13 篇，而且文体很特殊，调了就是过拟合。

## 已知局限

1. **只看形式，不看质量。**一段没有任何套话、句子长短变化很大的文字，也可能写得很差。
2. **对文体敏感。**公文、说明书、学术摘要本来就需要分点和固定格式，分数会偏高；诗歌和对话会偏低。
3. **词表会过时。**模型在变，比如新模型已经少用破折号了。词表需要持续更新，欢迎提交 PR。
4. **可以被刻意规避。**删掉词表里的词就能降分，但这不等于没有 AI 味。第二章的研究也提到，专家在模型刻意避开"AI 词汇"之后，仍然能靠结构和原创性认出来。
5. **中文分句和统计都很粗糙**：按标点切句，按字计长，没有做分词。
