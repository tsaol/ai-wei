### 关于知乎

不访问知乎页面，就没有办法可靠地确认一篇文章是谁写的：搜索引擎记录的"作者"字段大多是作者简介，不是名字。为了不批量抓取知乎，这两位作者暂时没有收录。

## 怎么收集的

- 每个来源按发布日期**均匀抽样**，让不同时期都有代表。阮一峰只取"开发者手册""理解计算机""JavaScript"三个技术分类，不取周刊。
- 抓取间隔 3 秒以上。酷壳原站的文章页现在显示"数据库错误"，所以取自 GitHub 上的 Markdown 存档 [slan-ning/coolshell-markdown](https://github.com/slan-ning/coolshell-markdown)（742 篇）：只取 1,500 字以上的文章，2004–2023 年每年轮流抽样。
- 正文从页面的正文容器提取，转成 Markdown：**保留代码块和标题，去掉图片，文字不做任何改动。**很早期的文章（比如阮一峰 2010 年以前的）原网页就把代码放在普通段落里，所以没有代码块格式。
- 每个文件开头记录了标题、作者、日期、原文链接、抓取来源和许可。
